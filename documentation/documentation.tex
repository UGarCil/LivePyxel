\section{Introduction}
The process of building annotations for image-segmentation datasets is long, tedious and often expensive.
Domain experts may be willing to build the annotations, but may lack the time resources to familiarize themselves with complex GUIs.
\progname  is a Python library that integrates a user's webcam with an annotation tool. 

\section{Features}
The main features of \progname are:
\begin{itemize}
    \item Real-time image segmentation.
    \item User-friendly interface.
    \item Webcam integration.
    \item Modular in design for easy add on installation
\end{itemize}

\subsection{Modules}
The core functionality of the \progname software is encapsulated within the following modules:
\begin{itemize}
    \item \texttt{constants} - Initializes constants and structures accessed across modules.
    \item \texttt{ImageAnnotator} - Handles annotation, video capture and UI integration.
    \item \texttt{Bezierman} - Bezier spline manager.
    \item \texttt{Polyman} - Polygon tool manager.
    \item \texttt{UIMainWindow} - Contains the main user interface elements.
    \item \texttt{VideoDeviceManager} - Handles video device initialization and image saving.
\end{itemize}
